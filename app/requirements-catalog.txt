# Standard part catalogue - optional extras.
#
# Install after the main requirements:
#     pip install -r app/requirements-catalog.txt
#
# Both are Apache-2.0 and pinned to a commit rather than a tag: neither is
# published on PyPI, so an unpinned git URL means a demo can break when
# upstream moves.
#
# These install over git, so Git must be on PATH. On Windows that means
# Git for Windows (https://git-scm.com/download/win). Without this file
# the app still runs - app/catalog degrades to the families it builds
# itself, and app/tests/test_catalog_library.py covers that path.
#
# What each adds:
#   cq_gears      involute spur, helical, herringbone, ring, rack and
#                 bevel gears. Tip diameters verified against
#                 module x teeth + 2 modules.
#   cq_warehouse  12 screw head types and 7 nut types across M1.6-M64,
#                 plus sprockets, roller chain and ISO threads.
#
#                 Two caveats, found by testing rather than assumed. Its
#                 washers are broken in this revision - every standard,
#                 every size, a non-closed shell with roughly twice the
#                 correct volume - so washers come from app/catalog/parts.py
#                 and the router refuses to serve one. And it imports
#                 importlib.resources.open_text, removed in Python 3.13,
#                 so this pin needs Python 3.11 or 3.12.
